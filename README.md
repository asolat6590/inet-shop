# CYBERPULSE — Интернет-магазин комплектующих для ПК с визуальным конструктором и калькулятором FPS

Современный интернет-магазин компьютерных комплектующих и кастомных сборок ПК, разработанный для рынка Узбекистана с расчетом в узбекских сумах (UZS), поддержкой двух языков (RU / EN), интерактивным 2D-визуализатором сборки, калькулятором FPS в 20 самых тяжелых играх и интеграцией с Telegram Bot.

---

## 🌟 Ключевые возможности

### 1. 🖥️ Интерактивный визуальный Конструктор ПК (PC Builder)
- **Пошаговая ручная сборка**: Корпус, Процессор, Материнская плата, Кулер/СЖО, Оперативная память, Видеокарта, Накопители, Блок питания.
- **Живая визуализация процесса сборки**:
  - Интерактивное 2D-шасси с прозрачным стеклянным окном.
  - Компоненты динамически устанавливаются на свои посадочные места в режиме реального времени.
  - Переключатель ARGB подсветки (Cyan, Violet, Emerald, Cyber Pink, White).
  - Интерактивные кликабельные зоны деталей прямо на схеме ПК.
- **Движок проверки совместимости**:
  - Контроль соответствия сокетов (LGA1700 vs AM5).
  - Контроль типа памяти (DDR4 vs DDR5).
  - Контроль габаритов видеокарты и высоты процессорного кулера.
  - Калькулятор пикового энергопотребления (TDP) и рекомендуемой мощности БП с запасом +30%.

### 3. 🤖 Оплата и уведомления через Telegram Bot
- Файлы **`.env`** созданы в корне проекта и в папке `server/.env`:
  ```env
  # Токен вашего бота от @BotFather
  TELEGRAM_BOT_TOKEN=

  # Telegram Chat ID менеджера (кому присылать чек)
  TELEGRAM_MANAGER_CHAT_ID=
  ```
- Покупатель оформляет заказ с указанием телефона (+998...) и ника в Telegram.
- Менеджер мгновенно получает подробную карточку заказа прямо в Telegram:
  - Номер заказа и контакты покупателя.
  - Полный состав собранной конфигурации ПК с ценой за каждую деталь.
  - Итоговая сумма в сумах (UZS).
  - Интерактивные inline-кнопки: `[✅ Подтвердить оплату]`, `[❌ Отклонить]`, `[💬 Написать клиенту в TG]`.
- Настройка токена бота и Chat ID менеджера также доступна прямо из скрытой админки с функцией тестового пинга.

### 4. 🌐 Языки и валюта
- Двуязычный интерфейс: **Русский (RU)** и **Английский (EN)** с мгновенным переключением.
- Все цены и расчеты в **Узбекских сумах (UZS)** с локализованным форматированием.

### 5. 🔒 Скрытая панель администратора (Hidden Admin)

- Пароль по умолчанию: `admin123` (можно изменить в настройках).
- Возможности:
  - Дашборд со статистикой выручки и заказов.
  - Добавление, редактирование и удаление комплектующих.
  - Добавление новых игр (21-я, 22-я и т.д.) в базу FPS-калькулятора.
  - Просмотр и изменение статусов заказов покупателей.
  - Настройка Telegram Bot токена и Chat ID владельца.

## 🚀 Запуск проекта

### Быстрый старт (Production / Демо):
```bash
# 1. Запуск сервера (сервер сразу отдает и REST API, и собранный клиент на порту 5000)
cd server
node src/index.js
```
Открыть в браузере: `http://localhost:5000`  
Скрытая админка: `http://localhost:5000/vault-admin-99`

---

### Разработка (Development mode):

1. **Сервер (API + Telegram Bot)**:
```bash
cd server
npm run dev
```

2. **Клиент (React + Vite + Hot Reload)**:
```bash
cd client
npm run dev
```
Открыть в браузере: `http://localhost:3000` (с автоматическим проксированием запросов на бэкенд).

3. **Повторное сидирование базы данных**:
```bash
cd server
npm run seed
```
